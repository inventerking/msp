# Data dictionary

Status: **planning, pending approval.** This defines intent. It is not a migration and no SQL has been run.

## Conventions

- **Timestamps** are `timestamptz` in UTC. Columns are `NOT NULL` unless the Null column says yes.
- **Money** is `bigint` minor units with an ISO 4217 `currency`. Floating point is not used for money. Basis points (`*_bps`) carry discounts.
- **Primary keys** are UUIDv7 generated by the application, chosen for index locality. Natural keys are used only for reference data (`shared.countries`, `platform.settings`) and link tables, as those rows are looked up by the natural key.
- **Scope:** *Tenant-owned* tables have `tenant_id NOT NULL`, RLS, and `UNIQUE (tenant_id, id)`. *Global* tables have no tenant data. *Mixed* tables allow a null `tenant_id` for platform-level rows.
- **FK** is an enforced foreign key. **Logical ref** is an ID with no foreign key, because it crosses a module boundary (ADR-005) or points into a partitioned table. Application services validate logical refs.
- **Retention** periods marked *proposed* or *legal review* are starting points, not legal advice (D-14).
